# Sanyal Jr. Personal Website

A responsive personal portfolio website designed with a black, red and white visual identity.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — menu, scroll reveal and active navigation
- `assets/logo.png` — supplied Sanyal Jr. logo

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `sanyal-jr`.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you your live website URL.

## Personalize
In `index.html`, replace:
- `your-email@example.com`
- `facebook.com/yourprofile`
- `github.com/yourusername`
- project descriptions
- gallery placeholders

You can also replace `assets/logo.png` with another logo while keeping the same filename.
